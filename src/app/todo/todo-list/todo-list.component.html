นี่คือหน้าแรกของเว็บไซต์ที่จัดทำขึ้นเพื่อแสดงโปรเจกต์ของผม โดยเน้นการออกแบบ UI ที่เรียบง่าย สวยงาม และใช้งานได้จริง ข้อมูลต่าง ๆ ที่แสดงในหน้านี้มีจุดประสงค์เพื่ออธิบายแนวคิดของระบบ ฟีเจอร์ต่าง ๆ และแนวทางการพัฒนา

ดูเพิ่มเติม

เกี่ยวกับโปรเจกต์

โปรเจกต์นี้พัฒนาด้วย Angular Standalone โดยใช้ HTML และ TypeScript UI ใช้ Tailwind CSS สำหรับฝั่ง Backend ใช้ Express ในการจัดการ API และเชื่อมต่อกับ ฐานข้อมูล PostgreSQL รันได้ผ่านคำสั่ง ng s และ bun dev.

สิ่งที่ได้เรียนรู้

- การใช้ Angular แบบ Standalone Component
- การจัดการ Styling และ Layout ด้วย Tailwind CSS
- การสร้าง REST API ด้วย Express และเชื่อมต่อกับฐานข้อมูล PostgreSQL
- การจัดการและรันโปรเจกต์ด้วยคำสั่งที่แยก Frontend และ Backend อย่างชัดเจน
- การทำงานแบบ Full-stack
- ผมคิดว่าการเขียน Component แบบนี้น่าจะง่ายด้วยการทำงานเป็นทีม
